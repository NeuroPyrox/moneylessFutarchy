# Coding style

- Prefer camel case with first letter lowercase.
- Use functional programming, making the code as pure as reasonably possible.
- Use a TDD style, implementing unit tests before writing the minimum code to make them pass, then refactoring.
- Prefer not to return values from functions that have side effects.
- Prefer the minimal amount of unit tests to satisfy a user story.
- Prefer to split up a user story into the smallest amount of sub stories.
